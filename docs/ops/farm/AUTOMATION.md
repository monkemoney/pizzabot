# אוטומציה של החילוץ — Kfar Saba Urban Farm

> **עיקרון:** פעם אחת = backfill ידני-למחצה (2023–2025). מהיום והלאה = **הנתונים נרשמים לבד, בזמן אמת, דרגה R.** הגיליון הוא מקור האמת; כל מקור מזין אותו אוטומטית; אנשים רק **מתייגים ומאשרים**.
> **איפה זה רץ:** בתוך חשבון Google של העמותה (Apps Script) ועל המק של לימור/טירן (launchd). **אין שרת, אין דאטה שיוצא מהחשבונות שלהם.** החוצה — הגיליון הנגזר בלבד.

## הארכיטקטורה

```
                    ┌──────────────── חשבון Google של העמותה ────────────────┐
 Gmail ──filters──▶ │ Apps Script (טריגר שבועי): receipts → Money/Donors      │
 Google Form (QR) ─▶│ Attendance → Events (R)  ·  Calendar → Events            │──▶ Farm Data (Sheet)
 Drive (PDF קבלות) ▶│ קטלוג לרו״ח                                              │       │
 Instagram API ────▶│ פוסטים חדשים → Events(E) / Assets                       │       │
 Google Business ──▶│ ביקורות → Events(E) · פניות → Funnel                    │       ▼
                    └──────────────────────────────────────────────────────────┘   Digest חודשי
 מק (launchd, חודשי): osxphotos → timeline.py → קלאסטרים חדשים ─────────────────▶   (מייל ללימור,
 בנק/כרטיס → הנה״ח (QBO/Wave) → ייצוא CSV חודשי → ledger.py → Money ────────────▶    טירן, נווה)
 Wix/Square Bookings → ייצוא/webhook → Events + Money ──────────────────────────▶
```

## שכבה 3 — בקרה ודיווח (אוטומטי)
- **Digest חודשי** (Apps Script → מייל ל-3): אירועים ומשתתפים לפי אוכלוסייה · כסף נכנס/יוצא לפי שורה · **לא-מותאמים** (שורות בנק בלי קבלה) · **קלאסטרים לא מתויגים** · **S שנשארו** · סטייה מהתחזית.
- **בדיקות עקביות** בסקריפט: אירוע בלי משתתפים · תשלום בלי אירוע · כפילויות · תאריך עתידי.
- **לוג עיבוד**: טאב Log — תאריך · מקור · שורות · מי.

## שכבה 4 — החיבור למערכת המענקים
הגיליון = **Knowledge Base** של מערכת המענקים: מספרי המשתתפים, עלות למשתתף, תקציבי תוכניות ומדדי תוצאה **מתעדכנים לבד** ב-answer bank. בקשה שנכתבת בדצמבר משתמשת במספרים של נובמבר. **זה מה שהופך ״סקייל ואיכות״ לאפשרי:** אף מספר לא מוקלד ידנית.

## מה נשאר אנושי — בכוונה
1. **תיוג** קלאסטרים (סוג · אוכלוסייה · headcount) — לימור, 20 דק׳/חודש אחרי ה-backfill.
2. **אישור קטגוריות** חדשות בכסף — טירן, 15 דק׳/חודש.
3. **הסכמה** לכל נכס עם פנים/שם.
4. **הקליק** על כל הגשה.
