# רשת אימון בוט ההזמנות 🍕🤖

רשת בוטים שמאמנת את בוט ההזמנות, מוצאת באגים, וצוברת לו "וותק" (הבנה מצטברת) לאורך זמן.

## איך זה עובד

```
רשת פרסונות (בוטים-לקוחות)  →  שיחות מלאות מול הבוט האמיתי  →  שופט (LLM)  →  משפר
        ↑                              (בזיכרון, לא נוגע בפרודקשן)              │
        │                                                                       ▼
        └──────────────  lessons.md מוזרק לפרומפט  ←───────────  knowledge/ (הוותק)
```

- **הבוט הנבדק הוא האמיתי**: משתמש ב-`src/bot/prompts.js` (תפריט + הגדרות אמיתיים מ-Supabase, קריאה בלבד) ובאותו מודל כמו פרודקשן. אבל השיחה כולה **בזיכרון** — לא נשלחות הודעות וואטסאפ, לא נשמרות הזמנות, לא נוגעים בלקוחות אמיתיים.
- **12 פרסונות** ב-`personas.js`, כל אחת בודקת חזית אחרת (ריבוי תוספות, מחוץ לאזור, תזמון, מעבר לאנגלית, ביטול, מחירים, סלנג...).
- **השופט** (`lib/judge.js`) מדרג כל שיחה לפי רובריקה: הזמנה נכונה, מחיר, חוקים, הזיות, טון, מקרה קצה.
- **המשפר** (`lib/improve.js`) מסנתז מהמכלול: באגים, לקחים, ודאטהסט לאימון.

## הרצה

```bash
# ריצת אימון בסיסית (12 שיחות, כל הפרסונות)
node training/run.js

# יותר שיחות
node training/run.js --n 24

# פרסונה אחת ממוקדת (למשל אזור הבאג של תוספות)
node training/run.js --persona toppings-heavy --n 5

# לצבור את הלקחים לוותק (מעדכן את knowledge/)
node training/run.js --apply

# A/B: להריץ עם הלקחים שכבר נצברו מוזרקים לבוט — לראות אם השתפר
node training/run.js --with-lessons

# דוח בלבד בלי לגעת בוותק
node training/run.js --dry
```

כל ריצה כותבת דוח מלא ב-`training/reports/run-<זמן>.md` (כולל תמלילים).

## הוותק (`knowledge/`)

| קובץ | מה זה |
|------|-------|
| `lessons.md` | כללים שנלמדו מכשלים. **זה מה שהופך את הבוט לחכם יותר.** |
| `examples.jsonl` | דוגמאות few-shot (מצב → טיפול נכון) שנקצרו מתיקונים. |
| `dataset.jsonl` | שיחות איכותיות (ציון ≥85) — מועמדות ל-fine-tuning עתידי. |

## החזרת הוותק לבוט האמיתי

הלולאה **מציעה** לקחים; היא לא משנה את פרודקשן בשקט. שתי דרכים להחיל:

1. **הזרקה אוטומטית (מבוקרת)** — הגדר `BOT_LESSONS_ENABLED=true` בסביבה. אז `prompts.js` מזריק את `lessons.md` לפרומפט האמיתי. כבוי כברירת מחדל.
2. **מיזוג ידני** — קרא את הדוח, ואמץ את הלקחים הטובים ישירות לתוך `src/bot/prompts.js`. מומלץ ללקחים שהוכיחו את עצמם.

**מומלץ:** לפני הזרקה לפרודקשן, הרץ `--with-lessons` וודא שהציון הממוצע באמת עלה מול ריצה בלי לקחים.

## עלות

כל שיחה = מספר קריאות מודל (בוט Opus + לקוח Sonnet) + קריאת שופט אחת. שלוט בהיקף עם `--n`
ובמקביליות עם `SIM_CONCURRENCY`. מודלים ניתנים לשינוי ב-`config.js`.

# 🎓 בוטקאמפ — עיגון בשיחות אמיתיות + מקביליות/אוטונומיה

מעבר לרשת האימון (פרסונות מדומות), הבוטקאמפ מוסיף שני צירים שהם קריטיים לפני שסומכים על הבוט בייצור:
**(1) כשירות על שיחות אמיתיות**, ו**(2) ביטחון בטיפול במקביליות ללא התערבות אנושית**.

## A. עיגון בשיחות אמיתיות — `training/ingest/`
מפרסר ייצואי וואטסאפ אמיתיים ל-cases + תובנות. **דורש** את תיקיית הייצוא (ברירת מחדל `~/Downloads/יצוא שיחות בוט פיצה/`, אפשר לשנות עם `WA_EXPORTS_DIR`).
```bash
node training/ingest/parse-exports.js   # zips → data/sessions.jsonl (מנוקה + אנונימי)
node training/ingest/mine.js            # LLM → real-cases.jsonl + insights.md
```
> `data/`, `real-cases.jsonl`, `insights.md` ב-`.gitignore` — הם מכילים תוכן לקוחות אמיתי (מפוסבד אך לא לקומיט).

## B. Replay eval — `training/eval/replay.js`
מזין הודעות לקוח אמיתיות לבוט הנוכחי ומדרג. **מדד הכשירות הכי כן.**
```bash
node training/eval/replay.js --n 20            # 20 שיחות אמיתיות
node training/eval/replay.js --n 20 --with-lessons
```

## C. מגרש מקביליות ואוטונומיה — `training/concurrency/`
מריץ שיחות בו-זמנית מול **`handleMessage()` האמיתי** על **טנאנט בדיקה חד-פעמי** (מנוקה אחרי).
```bash
node training/concurrency/load.js --k 50       # 50 בו-זמנית
node training/concurrency/load.js --k 5         # smoke
node training/concurrency/test-tenant.js list   # לוודא שאין טנאנטי בדיקה תקועים
```
מודד: **autonomy rate** (הושלם ללא שגיאה/התערבות), **isolation** (tracers — אין דליפה בין שיחות/טנאנטים),
**same-phone race** (ה-race הידוע), **cache coherence** (TTL 3s), **latency** (p50/p95), ו-**fault injection**
(429/529/500 מוזרקים → degradation חינני, בלי אובדן/שיבוש). **בטיחות:** אפס שליחות אמיתיות (interception + חסימת axios),
וטנאנט הבדיקה מסומן `__test_tenant` — teardown מסרב לגעת בכל דבר אחר.

## D. תעודת בוגר — `training/bootcamp.js`
מריץ את שלושת השלבים (כל אחד בתהליך נפרד) ומפיק **report card** עם **GO/NO-GO** מול שערי סיום.
```bash
node training/bootcamp.js            # מלא (K=50)
node training/bootcamp.js --quick    # מהיר (בדיקת חיווט)
node training/bootcamp.js --with-lessons
```
שערים: L1–4 סינתטי (ממוצע ≥90, 0 קריטיים) · L5 אמיתי (ממוצע ≥80, <25% חלשים) ·
L6 מקביליות (autonomy ≥98%, 0 isolation, 0 דליפת HTTP, p95<8s, שלמות תחת תקלות).

## עלות ובטיחות של הבוטקאמפ
`load.js`/`bootcamp.js` נוגעים ב-Supabase האמיתי דרך **טנאנט בדיקה מבודד** בלבד, ומנקים אחריהם.
אף פעם לא נשלחות הודעות וואטסאפ/תשלומים אמיתיים. `push-notifier` ו-`savePendingPayment` מנוטרלים כדי
שה-schedulers בייצור לא יקלטו שורות בדיקה. הרץ עם `--k` קטן קודם.
