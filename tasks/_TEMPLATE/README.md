# Task workspace template (brain/parts/10-inner-world.md)

Copy this folder to `tasks/<yyyy-mm-dd>-<slug>/` when a task needs more than one session, more than one person,
or touches more than one repo. Below that threshold a brief is enough.

Any session that resumes the task reads `STATE.md` first. Every durable thought goes to a file before the next tool
call — the session's context is a cache, not the truth.

Loop: Understand (TASK) → Model (WORLD) → Decompose (PLAN) → Rehearse (PREMORTEM) → execute one slice →
checkpoint (STATE + LOG) → reflect → repeat until done-when is observed → RESULT.
